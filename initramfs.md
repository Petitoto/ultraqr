# UltraQR in initramfs

UltraQR is designed to be run from initramfs, to allow the user to verify the boot integrity before providing a decryption password. However, the process may vary depending on your installation.

## Using initramfs-tools
- Set up an initramfs hook to install UltraQR in the initramfs image: create and make executable `/usr/share/initramfs-tools/hooks/ultraqr`
```sh
#!/bin/sh

PREREQ=""

prereqs()
{
        echo "${PREREQ}"
}

case "${1}" in
        prereqs)
                prereqs
                exit 0
                ;;
esac

. /usr/share/initramfs-tools/hook-functions

copy_exec /usr/local/bin/ultraq
```

- Find the UUID of your boot drive: `lsblk -o +uuid`

- Add a premount script to run UltraQR on startup: create and make executable `/usr/share/initramfs-tools/scripts/init-premount/ultraqr` (replace `<BOOT_UUID>` with the UUID of your boot drive)
```sh
#!/bin/sh

PREREQ=""

prereqs()
{
	echo "${PREREQ}"
}

case ${1} in
	prereqs)
		prereqs
		exit 0
		;;
esac

mkdir /boot && mount -t ext2 -o ro /dev/disk/by-uuid/<BOOT_UUID> /boot
/usr/local/bin/ultraqr -verify -key /boot/ultraqr; read
umount /boot
```

- Update your initramfs image: `update-initramfs -u`

- Reboot once, initialize UltraQR, and save keys to your boot partition: `ultraqr -init -key /boot/ultraqr`


## Plymouth notes
UltraQR can be used along with Plymouth by saving the generated QR codes to a PNG file.

- Edit your Plymouth theme to include QR codes generated by UltraQR (`/usr/share/plymouth/themes/<THEME>/<THEME.script>`). The following code snippet provides functions to display QR codes:
```java
/* ULTRAQR */
fun centerUltraQR (image) {
  sprite = Sprite(image);
  sprite.SetX(X_CENTER - image.GetWidth() / 2);
  sprite.SetY(Y_CENTER - image.GetHeight() / 2);
  sprite.SetZ(10);
  sprite.SetOpacity(0);
  return sprite;
}
fun showUltraQR () {
  ultraqr.sprite.SetOpacity(1);
}
fun hideUltraQR () {
  ultraqr.sprite.SetOpacity(0);
}
ultraqr.image = Image("ultraqr.png");
ultraqr.sprite = centerUltraQR(ultraqr.image);
```

- Follow the installation using initramfs-tools, but use the following script for `/usr/share/initramfs-tools/scripts/init-premount/ultraqr` (replace `<BOOT_UUID>` and `<THEME>` with your values):
```sh
#!/bin/sh

PREREQ=""

prereqs()
{
	echo "${PREREQ}"
}

case ${1} in
	prereqs)
		prereqs
		exit 0
		;;
esac

mkdir /boot && mount -t ext2 -o ro /dev/disk/by-uuid/<BOOT_UUID> /boot
/usr/local/bin/ultraqr -verify -key /boot/ultraqr -out /usr/share/plymouth/themes/<THEME>/ultraqr.png &> /dev/null
umount /boot
```
